# MUNDARIA – Guardianes de la Huella

Prototipo educativo de realidad aumentada sobre huella digital (activa y pasiva).

## Archivos
- `index.html`: la experiencia (bienvenida, 2 desafíos, insignia).
- `assets/nebula.png`, `fenix.png`, `otrix.png`: criaturas.

## Tecnología
Cámara del celular (getUserMedia) + criatura superpuesta. No requiere librerías externas. Se publica con GitHub Pages (https).
